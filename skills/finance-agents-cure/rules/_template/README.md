# Site rules template

Copy this folder to `rules/<site>/` for a new EXSYS company and write one file per area:
`common.md, ar-insurance.md, ap-supplier.md, vat.md, payroll.md, cost-inventory.md, gl.md`.

Each line is one standing rule the site's finance team has stated, written as an instruction.
Start with `common.md` (cancelled-voucher status, branches, cost centres). Leave a file with only a
heading if the site has no rules yet — the agent then uses the defaults in its own definition.
